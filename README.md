# Локальный P2P Мессенджер FinalProjectSP

Консольное клиент-серверное приложение на языке C для обмена сообщениями и файлами в локальной сети. Программа работает по принципу P2P: каждый запущенный экземпляр одновременно является и сервером, и клиентом.

## Технологии
* **Язык программирования:** C (чистый синтаксис, без сторонних библиотек).
* **Системные вызовы:** Windows API (`<windows.h>`).
* **Межпроцессное/сетевое взаимодействие:** 
  * **Именованные каналы (Named Pipes)** — для надежного двустороннего обмена сообщениями и бинарными файлами.
  * **Почтовые ящики (Mailslots)** — для широковещательной (Broadcast) рассылки сообщений всем компьютерам в сети.

## Основной функционал
1. **Двусторонний чат:** обмен текстовыми сообщениями в реальном времени.
2. **Передача файлов:** возможность отправлять файлы любых форматов собеседнику напрямую.
3. **Широковещательная рассылка:** отправка сообщения сразу всем устройствам в локальной сети.
4. **Удобное подключение:** соединение происходит по **имени компьютера** (например, `KB37-212-C11`), без необходимости узнавать IP-адреса.
5. **История переписки:** автоматическое сохранение чата в файл `chat_history.txt` с возможностью просмотра через меню.
6. **Многопоточность:** серверная часть способна обрабатывать подключения от нескольких клиентов одновременно.

## Как пользоваться

1. Запустите скомпилированный файл `FinalProjectSP.exe`.
2. При старте программа выведет **Ваше имя компьютера в сети** — сообщите его собеседнику.
3. В главном меню выберите нужное действие:
   * Введите команду /connect, чтобы подключиться к другому ПК (введите имя ПК собеседника, либо `.` для тестирования на одном компьютере).
   * Введите команду /broadcast, чтобы отправить сообщение всем в сети (после комманды введите текст сообщения).
   * Введите команду /history, чтобы прочитать историю. История отдельно сохранится в файле chat_history.txt, который будет храниться в той же папке, что и программа.
4. **В режиме чата:**
   * Просто вводите текст для общения.
   * Для отправки файла используйте специальную команду: `/file имя_файла.ext` (например: `/file document.txt`). Убедитесь, что файл лежит в той же папке, что и программа. *Принятые файлы сохраняются с приставкой `recv_`.*
   * Для завершения сеанса введите слово `выход`.

## Требования для работы программы
* ОС Windows.
* Оба компьютера должны находиться в одной локальной сети.
* В настройках сети Windows (или в Брандмауэре) должен быть разрешен «Общий доступ к файлам и принтерам» (порты протокола SMB), иначе каналы не смогут установить соединение между разными ПК.
